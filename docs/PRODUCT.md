# Produto

## Problema

Planilhas financeiras são flexíveis, mas frequentemente tornam o registro diário burocrático.

## Proposta

Permitir registrar rapidamente e transformar os dados em:

- acompanhamento;
- planejamento;
- visão individual;
- visão compartilhada;
- projeção futura.

## Conceito de evolução

```text
Meu dinheiro
Seu dinheiro
Nosso dinheiro
```

## Público inicial

Casais que:

- possuem rendas separadas;
- dividem despesas;
- usam cartões diferentes;
- possuem metas conjuntas;
- querem manter individualidade financeira.

## Possíveis planos futuros

- Individual
- Casal
- Família

O MVP atual ainda não é uma aplicação SaaS multiusuário.
